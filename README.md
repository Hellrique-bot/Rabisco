# Rabisco

Caderno de estudo instalável (PWA). Tudo fica salvo no aparelho de cada pessoa.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub (ex.: `rabisco`).
2. Envie todos os arquivos desta pasta para a raiz do repositório (Add file > Upload files).
3. Em Settings > Pages, em "Build and deployment", escolha "Deploy from a branch", branch `main` e pasta `/ (root)`. Salve.
4. Em 1 a 2 minutos o app estará em `https://SEU-USUARIO.github.io/rabisco/`.

## Instalar no celular
- Android (Chrome): menu ⋮ > "Instalar app" ou "Adicionar à tela inicial".
- iPhone (Safari): Compartilhar > "Adicionar à Tela de Início".

## Atualizações
Ao alterar o `index.html`, troque `rabisco-v1` por `rabisco-v2` (e assim por diante) no `sw.js` para os celulares receberem a versão nova.
